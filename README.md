# Voucher Studio | Voucher Generator

A responsive web application designed to create, preview, and manage vouchers through a clean and intuitive user interface.

Built with **HTML5, CSS3, and Vanilla JavaScript**, this project demonstrates practical front-end development skills, DOM manipulation, event handling, and browser-based data storage.

## Overview

Voucher Studio is a front-end application that simplifies the process of generating and managing vouchers. It provides an interactive interface for creating vouchers and viewing saved voucher information.

This project was developed to strengthen practical web development skills and demonstrate the ability to build a functional, user-friendly web application.

## Key Features

- **Voucher Generation** — Create vouchers through an interactive form.
- **Live Preview** — Preview voucher details before using them.
- **Voucher Management** — View and manage generated vouchers.
- **Browser Data Storage** — Store voucher information using Local Storage.
- **Responsive Interface** — Adapt the layout to different screen sizes.
- **Interactive User Experience** — Handle user input and interface updates with JavaScript.

## Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- Git (required to clone the repository)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/voucher-studio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd voucher-studio
   ```

3. Open the project in Visual Studio Code.

4. Open `index.html` in your browser or run it using the Live Server extension.
